# Shared frontend code

Cross-feature configuration and platform utilities belong here. `config/defaults.ts` supplies the development server URL. User-selected server URLs remain runtime settings. Feature-specific storage and screen state stay with their feature; shared API types belong in the contracts package. `accessibility.ts` moves keyboard (web) or screen-reader (native) focus to a view with `moveFocus(node)`. `useFocusOnChange(key)` returns a ref that is focused on mount and whenever `key` changes (wizard titles on step change). `radio-group.ts` (`useRadioGroupKeyboard`) gives card-style radio groups the web radio-group keyboard pattern (roving Tab stop, Arrow keys, Space); its pure rules live in `radio-group-model.ts`.
