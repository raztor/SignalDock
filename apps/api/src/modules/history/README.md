# Conversations and recordings

`registerHistoryRoutes(app, {auth, history})` is mounted by application composition under the instance's `/api/v1` prefix. All endpoints require fresh authentication. List queries filter explicit authorized radio grants before pagination for every role, including administrators; every individual communication and recording request checks its radio permission again. Playback uses `history.read`; explicit download requires `recording.export`; corrections and notes use `history.write`; deleting communications and changing retention holds require instance administration.

Review aggregates: `GET /history/activity?radioId&frequencyHz&direction&days=7&tz=<IANA>` returns a complete local `days × 24` heatmap grid (`HistoryActivity`) using the same radio scope as list queries; communications are counted per 15-minute UTC slot in PostgreSQL and bucketed into the requested zone in `@signaldock/history`. `tz` must be an IANA zone name: it is matched case-insensitively against the runtime's zone list (aliases resolve to the canonical name), offset zones such as `+05:30` are rejected with 400, and the canonical name is returned as `timeZone`. Only canonical names are cached as formatters, so the cache is bounded. `GET /communications/:id/waveform?points=64` returns `CommunicationWaveform` peaks (0..1 full scale) and duration decoded from stored WAV or raw `audio/pcm;rate=` s16le recordings, authorized like playback; undecodable, missing, oversized or gap recordings, and stored artifacts that are gone or fail their integrity check, return empty peaks with the communication duration (always 200). Summaries are cached in a 500-entry in-memory LRU keyed by recording and point count, after authorization.

Routes cover frequency conversations, cursor-paginated communications, transcript/note/tag search, station notes, immutable human transcript revisions, audited metadata corrections, coverage intervals, and deletion. `GET /recordings/:id` returns private recording bytes with single HTTP byte-range support and HTTP416 for unsatisfiable ranges. Credentials remain in request headers. Responses are not cacheable; the artifact directory is never a static mount.

Persistence, source locks, deletion, retention, and PCM segmentation live in `@signaldock/history`. Wire `HistoryCaptureRecorder.onFinalized` to configured processing jobs after commit. Audio gaps remain visible, and optional processing must reject unavailable recordings. Schedule the worker's history maintenance handler for artifact cleanup and configured retention cutoffs. Source-bound work must use terminal `execution.commit` fencing.

Real PostgreSQL 18 integration tests cover API scopes, playback ranges, stale edits, deletion, and late transcript suppression. They use isolated schemas. Browser/native physical playback and live radio capture are separate rollout acceptance gates.
