# Applications

- [Client](client/README.md): Expo frontend for web, iOS, and Android.
- [API](api/README.md): TypeScript backend and authenticated domain API as it is implemented.
- [Worker](worker/README.md): planned background processing application.
- [Push relay](push-relay/README.md): planned optional notification delivery service.

Each implemented application has its own workspace manifest and entry point. Reserved application folders contain documentation only until their implementation package starts. Shared contracts and SDKs belong in `packages`; hardware integration belongs in `services`.
